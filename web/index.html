2获取笔记数据

填 user_id（小红书号）或 登录 key 都能拉，二选一。 服务端走「官方导出 + 数据接口」两路合并，字段包含曝光、观看、点赞、收藏、评论、分享、涨粉、 封面点击率、人均观看时长、弹幕。

API 说明

POST /api/login/start {"key":"随机键"} → 返回 qr（data URI）与 expires_in
GET /api/login/status?key=… → pending / success / expired，成功时带 user_id，并持续返回最新二维码
GET /api/notes?user_id=… 或 GET /api/notes?key=… → 全量笔记数据（二者任选其一）
GET /api/notes.csv?user_id=… 或 ?key=… → 直接下载 CSV
